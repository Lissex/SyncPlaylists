# Как безопасно получить токен Яндекс Музыки

Токен нужен для двух вещей:
- подключить аккаунт в приложении (`POST /accounts`, `{"platform": "yandex", "access_token": "…"}`);
  сервер проверит его через профиль Яндекса и сохранит только зашифрованным (AES-GCM);
- запускать live-тесты (`YANDEX_LIVE_TOKEN` в `.env`).

Пароль от Яндекса сервис не принимает и не хранит никогда.

## Способ: официальная OAuth-страница Яндекса

1. Войдите в браузере в свой Яндекс ID (тот аккаунт, музыку которого переносите).
2. Откройте DevTools (F12) → вкладка **Network** → включите **Preserve log**.
3. Откройте в этой же вкладке ссылку на OAuth-сервер Яндекса для клиента приложения
   Яндекс Музыки. Этот способ описан в документации библиотеки `yandex-music`:

   ```
   https://oauth.yandex.ru/authorize?response_type=token&client_id=23cabbbdc6cd418abb4b39c32c41195d
   ```

   Проверьте, что адрес начинается именно с `https://oauth.yandex.ru/`. Логин и пароль, если их
   спросят, вводите только на этом домене Яндекса.
4. Нажмите «Войти как …». Яндекс перенаправит на адрес вида
   `https://music.yandex.ru/#access_token=y0_…&token_type=bearer&expires_in=…`.
   Токен — значение `access_token` (начинается с `y0_`). Если страница успела перейти дальше,
   найдите этот адрес в списке запросов на вкладке Network.
5. Сразу положите токен туда, где он нужен:
   - для тестов — строкой `YANDEX_LIVE_TOKEN=y0_…` в `.env` в корне репозитория (`.env` в
     `.gitignore`);
   - для приложения — в форму или запрос подключения аккаунта.
   Затем закройте вкладку: адрес с токеном остаётся в истории браузера, его можно удалить
   оттуда.

Токен живёт около года (`expires_in`). Когда он протухнет, сервис переведёт аккаунт в статус
EXPIRED. Тогда нужно получить новый токен и подключить аккаунт заново.

## Чего не делать

- Не вводите логин и пароль Яндекса в сторонние сайты, Telegram-ботов, расширения и скрипты,
  которые обещают «достать токен». Им достаётся ваш аккаунт целиком.
- Не вставляйте токен в чаты (включая чат с ассистентом), issue, скриншоты, логи и коммиты. Токен
  даёт полный доступ к вашей Музыке: лайкам, плейлистам, истории.
- Не храните токен в коде и в `.env.example`.

## Если токен утёк

1. Откройте [id.yandex.ru](https://id.yandex.ru) → «Безопасность».
2. Отзовите доступ приложения Яндекс Музыки в разделе доступов или устройств (название раздела
   в интерфейсе может отличаться). Крайний вариант — «Выйти на всех устройствах»: он отзовёт все
   токены сразу.
3. Получите новый токен по инструкции выше и переподключите аккаунт в сервисе.

Для live-тестов, которые пишут в аккаунт (временный плейлист, лайки с последующим снятием),
можно завести отдельный тестовый аккаунт Яндекса.
